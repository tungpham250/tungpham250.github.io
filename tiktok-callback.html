Đang đọc mã…
Bước tiếp theo (làm trong vòng vài phút, mã hết hạn nhanh):
  1. Bấm Sao chép mã.
  2. Mở GitHub → Actions → Kết nối TikTok → Run workflow → dán mã vào ô code, chọn kênh (vi hoặc en) → Run workflow.
  3. Khoảng 1 phút sau, Telegram báo "Đã kết nối TikTok".
